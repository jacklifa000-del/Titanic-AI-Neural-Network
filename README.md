# Titanic Survival AI (PyTORCH) 

## PROJECT OVERVIEW
This project is a complete Deep Learning pipeline built with PyTorch. It takes cleaned 
titanic data and trains a Neural network to predict whether a passenger survive or not based on features like age, fare, and class.

##
Skills Used
**Pandas:*Loaded the cleaned CSV and separated features (X) from the target (Y).
**Scikit-Learn:** Used 'train_test_split' to split data and StandardScaler to normalize features.
**PyTorch:** Built a Multi-Layer Perceptron (Neural Network) using 'nn.Sequential', 'nn.Linear', and 'nn.ReLU'.
**Classification:** Used 'BCELoss' and the Sigmoid activation function for binary classification.
**Model Evaluation:** Achieved a testing accuracy of over 77%.
